# Glossary

| Term | Definition |
| --- | --- |
| Acceptance/acknowledgement letter | Controlled employee-facing document confirming receipt/acceptance of a resignation according to approved HR wording. |
| Asset disposition | Final documented outcome for a required asset item, such as returned, not issued, lost, damaged, waived or approved unresolved. |
| Baseline cohort | Cases measured before selected improvement automations are enabled. |
| Break-glass access | Exceptional, time-limited, approved access to restricted data for a defined technical or incident need. |
| Business day | A working day calculated using the approved America/Jamaica calendar and configured holidays. |
| Case snapshot | Immutable copy of approved employee/source fields used by a case, workflow and documents. |
| Clearance review | HR-controlled stage that verifies mandatory tasks, approvals, documents, notifications, assets and exceptions before completion. |
| Cohort suppression | Preventing or grouping reports with too few responses to reduce re-identification risk. |
| Controlled template | Versioned, approved content with declared placeholders and governance. |
| Effective separation time | Approved exact date/time at which employment/access separation takes effect for workflow scheduling. |
| Idempotency | Property that allows an operation to be retried without creating duplicate business effects. |
| Outbox | Persisted queue of approved outbound work committed with the related business transaction. |
| Pilot cohort | Cases processed during the controlled pilot under defined release conditions. |
| Post-rollout cohort | Cases processed after full production rollout. |
| Provider acceptance | Technical response indicating a provider accepted a request for processing; not necessarily final delivery. |
| Restricted HR data | Highest application classification for termination preparation, identifiable exit feedback, personal contacts, rehire eligibility and similar content. |
| Survey invitation token | High-entropy, one-time, expiring credential granting access only to a specific survey. |
| Task waiver | Authorized decision that an eligible task is not required for a case, with reason and evidence. |
| Workflow definition | Versioned configuration specifying tasks, conditions, owners, due rules, dependencies and completion controls. |
| Workflow instance | Case-specific copy/reference of a workflow version and its instantiated tasks. |
